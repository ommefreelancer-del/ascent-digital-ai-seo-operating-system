# Inputs & Outputs

A quick reference for what to provide for common requests, and what you'll get back.

| You ask for... | What to provide | What you get back |
|---|---|---|
| A website audit | A URL (and, optionally, a target keyword) | A scored, prioritized list of real findings across technical, on-page, and content areas |
| Keyword research | A topic, business type, or niche, and optionally a location | Real keyword and search-intent data |
| Written content (article, landing page, etc.) | A topic or business objective, and any brand guidelines you want followed | A finished draft with meta title/description, sections, FAQs, relevant images, and a quality/originality check result |
| A technical fix (after an audit) | Confirmation that you want the found issue fixed, and a connected repository | A specific proposed change to review and approve or reject; once approved, confirmation the fix was applied and re-verified |
| A website/code change | A description of the change you want, and a connected repository | A proposed plan and draft to review and approve or reject; once approved, confirmation the change was applied |
| A performance report | A connected Google Search Console and/or Bing Webmaster Tools account | A report built from your real, current search performance data |
| Competitor research | A competitor's URL or name | Real information gathered about that competitor's site |
| Prospect discovery (link-building) | A niche, target country/language, or a specific URL to investigate | A list of real, evidence-based prospects, with anything unconfirmed honestly labeled |
| Stock images/design assets | A description of what you need | Real, royalty-free search results |
| A spreadsheet cleanup | A connected Google Sheets account and confirmation to proceed | A proposed cleaned version to review; once approved, the real sheet is updated |

## General notes

- If a request needs a connected account you haven't set up yet, the system tells you clearly what's missing rather than guessing.
- If a request describes an action that requires your approval before it's real (a technical fix, a website change), you'll always see the exact proposed change first — see `client/APPROVALS_AND_HUMAN_CONTROL.md`.
- You never need to format your request in a special way — describe what you need in plain language, and follow up conversationally if the first reply isn't quite what you wanted.
