# Frequently Asked Questions

**Do I need to know which specialist to ask for?**
No. Describe what you need in plain language, and the system routes your request automatically. You can still ask for a specific capability by name if you prefer — see `client/AGENT_GUIDE.md`.

**Will the system ever change my live website without asking me first?**
No. Any real, production-affecting change always stops for your explicit approval first. See `client/APPROVALS_AND_HUMAN_CONTROL.md`.

**How do I know if an answer is based on real data or just the AI's general knowledge?**
See `client/AGENT_GUIDE.md` and `client/FEATURES_AND_CAPABILITIES.md` — many capabilities are explicitly marked as real/data-backed vs. expert guidance. If you're ever unsure about a specific reply, just ask.

**What do I need to connect to get full value from the platform?**
It depends on what you want. A basic website audit needs nothing connected. Real search-performance reporting needs Google Search Console or Bing Webmaster Tools. Real technical fixes and website changes need a connected GitHub repository. See `client/GETTING_STARTED.md`.

**Can I have multiple people on my team use one account?**
The platform currently supports a full-access login and a separate read-only login on the same account, but not a full multi-seat team/organization system. Ask your administrator if you need more than this.

**What happens if I reject a proposed change?**
Nothing changes. The proposal is discarded, and you can ask the system to try a different approach or propose something else.

**What happens if an approval expires before I act on it?**
Ask the system to re-propose the change — it will regenerate the proposal based on the current state of your site rather than an outdated one.

**Is my data shared with other customers?**
No. Every account's data is kept separate and is only ever accessible to that account. See your administrator if you'd like more detail on how this is enforced.

**Something isn't working — what do I do?**
Start with `client/TROUBLESHOOTING.md`, then contact your administrator if the issue isn't resolved there.
